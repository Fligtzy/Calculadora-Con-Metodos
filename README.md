# Calculadora con métodos en C#

Actividad 1: calculadora de consola que usa métodos para cada operación.

## Descripción

El programa pide dos números por consola y muestra:

- Suma
- Resta
- Multiplicación
- División (valida la división entre cero)

El `Main` solo lee los números, llama a los métodos y muestra los resultados.

## Métodos

| Método | Descripción |
|---|---|
| `Sumar(a, b)` | Retorna `a + b` |
| `Restar(a, b)` | Retorna `a - b` |
| `Multiplicar(a, b)` | Retorna `a * b` |
| `Dividir(a, b)` | Retorna `a / b` o un mensaje de error si `b` es 0 |
| `LeerNumero(mensaje)` | Muestra el mensaje y retorna el número digitado |

## Requisitos

- .NET 6 o superior
- Visual Studio o la CLI de .NET
